# Publish this book on GitHub Pages

The reader is ready for static hosting. Create an empty GitHub repository, upload this entire folder, then enable **Settings → Pages → Source: GitHub Actions**. The included workflow deploys automatically when the `main` branch is updated.

Your book URL will be:

`https://YOUR-GITHUB-USERNAME.github.io/YOUR-REPOSITORY-NAME/`

All file links in the book are relative, so it works at that address without further edits.
